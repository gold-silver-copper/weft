# Decision: ecs

> **Amended by [`0002-improve-ecs.md`](0002-improve-ecs.md).** That record replaces this one's Frozen API and its claims. The Frozen API below is 0002's P1–P8, verbatim, and the claims table is 0002's, verbatim. Where the rest of this record disagrees with them, they win.

## Context

The question: what is the most powerful, most minimal, most type-safe and most idiomatic ECS possible for weft, a crate for complex text games whose world is a graph of relations? The design may use any macros and nightly features. It may not use `unsafe`, dependencies or panics.

These constraints decided it:

- **Relations.** Many-to-many relations exist from day one. Relation endpoints are typed: `Exit` connects only `Room` to `Room`, and `In` can't point at a `Player`.
- **Graph states that must be impossible:**
  - an item in two containers, or in none
  - an edge that points at a despawned entity
  - a one-way door where the game meant two-way
  - a forbidden cycle
- **Handles.** Stale handles are impossible: if a handle exists, the entity exists.
- **Queries.** Queries can traverse the graph at any depth.
- **Reactions.** Reactions are declared once.
- **Checking.** Rules are enforced by the type system. `cargo check` errors are preferred.
- **Taste rules.**
  - Plain `&`/`&mut` access.
  - Systems are plain functions.
  - No `TypeId` lookups.
  - Few concepts and a small implementation.
- **Canonical programs.** The seven programs P1–P7 must compile. P5 in particular adds a relation, a drop-in module and a component without editing a central list.

After review and spikes, the marks left five options standing: **a**, **c**, **d**, **e** and **f**. Each was marked "spike" by the reviewers, and each spike passed `cargo check --offline --examples` with P1–P7 compiling. The reviewers rejected **b** and **g**. So there is more than one surviving option, and this record recommends one.

## Decision

**Adopt option d, Typed entity kinds**, with the changes its spike found were needed:

- **Kinds are types.** Every entity has a kind (`Room`, `Item`, `Player`), and the kind is in its handle's type: `Id<'t, K>`. The handle is branded by the turn's invariant lifetime.
- **Sets.** Kind sets (`set!`, `is!`) are open unions that any module can join. Relations are declared between kinds and sets in one `relation!` line. That line gives:
  - the shape: `->` or `<->`
  - the arity: `one`, `opt` or `many`
  - the loop rule: none, `acyclic` or `cyclic`
  - the despawn policy: `cascade`, `detach`, `spill` or `refuse`
  - an optional `on_relate` hook
- **Required edges.** `kind!(Item needs In)` makes the edge a required argument to `spawn`. A `one` relation has no `unrelate`, and relating it again is the move.
- **Despawn.** Despawns are deferred to the end of the turn and checked against a deletion plan. Settings are the data of the root entity.

**Why d, from the evidence:**

- **All three spike questions were answered in its favour** (spike report d):
  - **Inference.** `t.relate(lamp, In, me)` infers without annotations, in both concrete code and generic `G: Has<…>` code. rust-analyzer `analysis-stats` reports `exprs: 5976, ??ty: 0 (0%), ?ty: 0 (0%)`.
  - **Wrong endpoints and one-way doors.** These fail as E0277 in rustc and in rust-analyzer, and E0283 never appears:
    - `` `game::Room: Member<game::Item>` is not satisfied ``
    - `` `game::Exit: Value` is not satisfied ``
  - **Return types.** `relate` still normalizes to `()` for infallible relations inside generic functions.
- **Correctness under change was fuzzed.** The reviewer asked whether deferred despawn could leave a plan that fails at turn end. `fuzz_plan.rs` ran `3000 worlds x 40 turns: check() held every turn; 607469 ops applied, 52740 refused`. With the relate-time check disabled, it fails at once (`seed 2 turn 26`). So the plan guarantee depends on that check, and the check holds.
- **Handles and entities stay in step.** Nothing is freed before the turn ends, and no `Id` outlives its turn. So "if a handle exists, the entity exists" is literally true, doomed entities included. Option c's consuming despawn was meant to be stronger. Its own spike showed that old handles still exist as `Copy` values that simply can't reach anything (spike report c, "confirms the objection"). So c's extra continuation-passing machinery buys less than it claimed.
- **Reuse without a world-wide list.** Open sets let a reusable `containers` module ship its own `Holder` set, which the game's kinds join with one `is!` line (P5). Modules meet only in `game!`. P7 turns NPCs off by leaving `Folk` out.
- **Tooling and size.** It runs on stable Rust. The spike library is 1,626 lines, against today's 2,862. It has 12 concepts.

**Changes from the option as written.** The spike found these were needed, and they are part of this decision:

1. **No marker parameter on endpoints.**
   - The option's `impl Is<'t, R::Source, M>` breaks every `target::<X>(…)` turbofish with E0107. Endpoint conversion is instead one impl, `impl<'t, X: Member<E>, E> Is<'t, E> for Id<'t, X>`, plus a reflexive `Member<K> for K` that `kind!` and `set!` emit.
   - `Relation` declares `type Source: Stored + Member<Self::Source>`, and the same for `Target`, so code that is generic over the relation compiles.
2. **Genesis `relate` returns `Result` exactly when the relation is `acyclic`.** A cycle can still be written during genesis. Genesis `spawn` always returns `Id`.
3. **The root kind is stored as an ordinary table and implements `Has<Root>`.** `Needs` has separate impls for `Genesis` (no hook bounds) and `Live`.
4. **A blanket `impl<G: Schema, S: Set> Has<S> for G`** lets hook bounds name sets, such as `Walker`.
5. **`module!` emits a `#[macro_export]` callback macro that `game!` invokes.** Items passed through it must be in scope where `game!` is written.
6. **"An item in no container" fails as E0308,** not E0277: `` expected `(In, _)`, found `()` ``. It is still a `cargo check` error, and the P6 doctest says `compile_fail,E0308`.

**What would change this recommendation:**

- **Choose a instead** if cycle safety decided at the call site is worth a central schema. In a, a `relate` that could close a cycle fails to compile with a custom message, so the caller has to write `try_relate` (spike report a, Q1). The costs are real: central list edits (P5), a copied schema for `Solo` (P7), and `#![recursion_limit]` once a schema has about 65 names.
- **Choose c instead** if despawn must take effect immediately inside the turn, rather than at turn end, and the continuation-passing `despawn` is acceptable.

## Options considered

- **a: Closed schema, maximum proof.** One `schema!` per world, with Peano-indexed kind and group lists. These prove endpoints, spawn links and the `relate` vs `try_relate` cycle split at compile time.
  - Not rejected: the reviewers marked it spike, and the spike passed. The Peano logic gave readable `on_unimplemented` errors, and the two-bound generic command ran on both `Cave` and `GiveWorld`.
  - Not chosen, because of what the spike showed:
    - **P5 still edits the central list,** both `components: [...]` and `relations: [...]`, and P7 duplicates the schema.
    - **The macro hits the recursion limit.** `schema!` expansion hits the default limit at about 65 listed names (`recursion limit reached while expanding $crate::__weft_list!`).
    - **The fallback is the same as d's.** `Index` falls back to `Box::leak(Box::default())`, and `target` falls back to `Id::new(usize::MAX)`.
    - **Same-kind cycles are still runtime checks,** behind `try_relate`.
- **b: Composable schemas.** A world is a tuple of modules, resolved by inferred-path `Has<T, I>`, and roles are generated enums. **Rejected by the reviewers:**
  - "same-kind acyclicity is explicitly a runtime check, contrary to the brief's type-level enforcement and forbidden-cycle compile-fail requirements."
  - "breaks the constraint that graph traversal across relations ("items in any container, at any depth, in the room the player is in") is one query, and fails the drop-in module constraint by requiring macro-generated closed role enums."
- **c: Branded handles.** `despawn` consumes the `Turn` and continues in a newly branded closure. `Keep` re-brands the handles that survive.
  - Not rejected: marked spike, and the spike passed. Every higher-ranked closure inferred without annotations, and misuse gave E0382 or lifetime errors.
  - Not chosen:
    - **Old handles survive as values.** The spike confirmed they still exist as `Copy` values after a despawn; the guarantee is only that they can't reach an entity.
    - **Same weaknesses as d.** Reads still rely on a `Default` fallback (`Col::fallback`), and a chest inside itself is still a runtime `Err(Cycle)`.
    - **Continuation-passing is costly.** Every despawn nests a closure, and a handle has to be re-kept at every level. A misuse error (E0521) points at the valid line where the handle was created.
    - **Net result.** Compared with d, the continuation-passing machinery adds little guarantee.
- **e: Everything is an edge.** Components, settings and relations are all edges, and queries are `find!` path patterns.
  - Not rejected: marked spike, and the spike passed. `find!` worked in plain `macro_rules`.
  - Not chosen:
    - **Total reads were only reached by leaking.** Handles became references to records created with `Box::leak`, and "every record is leaked … never freed, not even when the `World` is dropped".
    - **`one` values can't be mutated.** `get_mut` gives E0277.
    - **Runtime type lookups.** `all` and `narrow` use `Any` downcasting, against the rule that nothing is looked up by `TypeId`.
    - **Spawn rows are positional.**
    - **The leak-free version brings back a central list.** It needs one arena per kind and a `World<'a, G>` type.
    - **Instance acyclicity is still a runtime check.**
- **f: Transactions with typed invariants.** A by-value `Tx<'t, S, D>` counts debts as a Peano number. `detach` hands out `Loose` tokens that must be paid back before `commit` exists.
  - Not rejected: marked spike, and the spike passed. rust-analyzer found 0 unknown types.
  - Not chosen:
    - **Nightly only.** It needs nightly `decl_macro`.
    - **Errors land in the wrong place.** A forgotten token is reported where the debts meet, "never at the dropped token".
    - **A soundness hole had to be closed by removing an API.** `despawn(Loose)` let `Paid` reads return `#4294967295`.
    - **A refused `relate` consumes the transaction.** So a missing item rolls back the whole turn, including the clock tick. Recovering from it needs `Result<Tx, (Tx, E)>` shapes everywhere.
    - **The store is cloned twice per transaction.**
    - **Obligated edges can only be detached one at a time.**
- **g: Ownership is the graph.** Containment is Rust ownership through `Bag<T>`, and only non-exclusive edges live in a graph. **Rejected by the reviewers:**
  - "`Bag::take` permits a live item in no container, violating the mandatory exactly-one invariant; containment also becomes a separate hierarchy feature contrary to the few-concepts taste rule."
  - "breaks the taste rule "Minimal: few concepts" (hierarchy is a separate `Bag<T>` API rather than a relation) and the constraint that graph queries can traverse from containers to items at depth in one query."

## Consequences

**Gets easier:**

- **One fact per relation.**
  - Moving an item is one `relate`.
  - Both directions come from a single stored edge (`targets` and `sources`).
  - A two-way `Exit` is one record holding a label for each direction.
- **Wrong-shaped graphs don't compile.** Wrong endpoints, one-way doors on `<->` relations, `unrelate` on `one` relations and spawning without required edges all fail under `cargo check`.
- **Commands say what they touch.** They are plain generic functions whose `Has<…>` bounds list exactly what they touch. P6 runs `take` against `Bare`, a smaller game.
- **Parts of a game can be turned off** by leaving a module out of `game!` (P7 `Quiet`).
- **Durable facts are graph facts.** Anything that must last across turns is an edge from the root, such as `Start` or `Plays`, and the despawn policy protects it.

**Gets harder:**

- **Handles last one turn.** No handle survives its turn, so games find entities again by name, from the root, or by walking edges.
- **Lifetimes show up in signatures.** Every function that takes handles must name `'t`.
- **Generic commands carry long bounds.** P5 `give` has six `Has` bounds.
- **Despawn is deferred.** A doomed entity stays visible and usable until the turn ends. `t.is_doomed` reports it, and relating into it can return `Refused::Doomed`.
- **Same-kind cycles are refused at runtime.** A chest inside itself is `Err(Refused::Cycle)`, not a compile error. No surviving option makes this a type error. The reviewer's objection to d stands on this point, and this decision accepts it.
- **`Index` has an unreachable fallback.** `t[id]` falls back to a per-kind `Default` slot on a branch that can't be reached. Kinds must derive `Default`. The branch is counted and fuzzed, not proved by types.
- **Hooks see only their own relation.** A hook's bound is fixed to `Has<R> + Has<R::Source> + Has<R::Target>`, so a reaction that touches another relation doesn't compile. The `on_relate = f: Module` extension was sketched but not built, and it is not part of this decision.
- **`cast` compares strings at runtime.** It compares a `module_path!()` string tag. That is not `TypeId`, but it is still a dynamic comparison.
- **Module names must be unique.** `module!` callbacks are `#[macro_export]`, so two modules with the same name in different Rust modules collide.
- **One diagnostic points the wrong way.** Forgetting `Has<In>` reports `` `In: Set` is not satisfied ``.

**Deleted:**

- **All of today's `src/`,** about 2,860 lines:
  - `bundle.rs`, `component.rs`, `entity.rs`, `event.rs` (the only `TypeId`/`Any` code), `query.rs`, `relation.rs`, `schedule.rs`, `schema.rs`
  - the old `world.rs`
- **`tests/weft.rs`** (27 tests) and **`examples/school.rs`.**
- **Old public API:** the public `Entity` and `NoSuchEntity`, resources, change ticks, observers, `Schedule`, and the loan and query machinery.
- **`#![no_std]`.** The `#![forbid(...)]` block and `clippy.toml` stay unchanged.

**Added:**

- **New modules:** `decl.rs`, `id.rs`, `macros.rs`, `store.rs`, `turn.rs` and a new `world.rs`.
- **Remaining work, about 600–1,000 lines beyond the spike** (spike report d):
  - declaration checks: a `one` relation must appear in its kind's `needs`; coherence rejects disjoint loops over overlapping sets; `cascade` from the root is rejected at declaration
  - two-way `one` and `opt` edge cases
  - `Needs` impls for three or more needs
  - docs
  - a `compile_fail` suite with one test per invalid state
  - a dependency-free xorshift fuzzer that runs the hidden `World::check`

**Migrations:** none are owed. Compatibility with today's weft is a non-goal. Existing tests and examples are rewritten against the new API.

## Frozen API

P1–P7 are option c's programs as spiked, with two spike-driven edits: user crates enable only `decl_macro`, and P5's `needs`-shape doctests expect E0271 (both from c spike Q3). P8 is new: it combines c's record-parsing with f's fingerprint pinning and checks the claims register.

### P1: Rooms, exits and taking an item

```rust
#![feature(decl_macro)]
use weft::*;

#[derive(Debug)]
pub struct Settings;
kind!(root Settings needs Start, Plays);

#[derive(Debug)]
pub struct Room {
    pub name: &'static str,
    pub desc: &'static str,
}
kind!(Room);

#[derive(Debug)]
pub struct Player;
kind!(Player needs At);

#[derive(Debug)]
pub struct Item {
    pub name: &'static str,
}
kind!(Item needs In); // an `Item` can't be spawned without its container

set!(pub Holder);
is!(Room, Player: Holder);

// A two-way exit is one fact with a label for each direction.
relation!(pub struct Exit(pub &'static str): Room <-> Room, many, cyclic, detach);
// `Item` is not a `Holder`, so `In` can't loop and needs no loop rule (`game!` checks this).
relation!(pub struct In: Item -> Holder, one, cascade);
// Where the player stands. Setting it runs `entered`, which may use anything in `Map`.
relation!(pub struct At: Player -> Room, one, refuse, on_relate = entered: Map);
relation!(pub struct Start: Settings -> Room, one, refuse);
relation!(pub struct Plays: Settings -> Player, one, refuse);

module!(pub Map { kinds: [Room, Player, Item], relations: [Exit, In, At, Start, Plays] });
game!(pub Game: Settings [Map]);

fn entered<'t, G: Map>(t: &mut Turn<'t, G>, _: Id<'t, Player>, room: Id<'t, Room>) -> Result<(), Refused> {
    println!("You enter the {}.", t[room].name);
    Ok(())
}

fn describe<'t, G: Map>(t: &Turn<'t, G>, room: Id<'t, Room>) {
    println!("{}\n{}", t[room].name, t[room].desc);
    for (to, exit) in t.targets::<Exit>(room) {
        println!("  {}: {}", exit.0, t[to].name);
    }
    for (item, _) in t.sources::<In>(room) {
        println!("  There is a {} here.", t[item].name);
    }
}

/// `take <noun>`. `In` is exactly-one, so relating the item again *is* the move.
fn take<'t, G: Map>(t: &mut Turn<'t, G>, me: Id<'t, Player>, noun: &str) -> Result<bool, Refused> {
    let here = t.target::<At>(me);
    let found = t.sources::<In>(here).map(|(item, _)| item).find(|&item| t[item].name == noun);
    match found {
        Some(item) => t.relate(item, In, me).map(|()| true),
        None => Ok(false),
    }
}

fn main() -> Result<(), Refused> {
    let mut world = World::<Game>::new(|t| {
        let hall = t.spawn(Room { name: "Hall", desc: "A draughty hall." }, ());
        let cellar = t.spawn(Room { name: "Cellar", desc: "It smells of apples." }, ());
        let garden = t.spawn(Room { name: "Garden", desc: "Roses, everywhere." }, ());
        t.relate(hall, (Exit("down"), Exit("up")), cellar);
        t.relate(hall, (Exit("north"), Exit("south")), garden);
        t.relate(cellar, (Exit("tunnel"), Exit("trapdoor")), garden);
        t.spawn(Item { name: "lamp" }, (In, cellar));
        t.spawn(Item { name: "rug" }, (In, cellar));
        let me = t.spawn(Player, (At, hall));
        t.spawn(Settings, ((Start, hall), (Plays, me)))
    });

    world.turn(|t| -> Result<(), Refused> {
        let me = t.target::<Plays>(t.root());
        let here = t.target::<At>(me);
        describe(t, here); // "Hall", "down: Cellar", "north: Garden"

        // "go down": `entered` prints "You enter the Cellar."
        let down = t.targets::<Exit>(here).find(|(_, exit)| exit.0 == "down").map(|(room, _)| room);
        let Some(cellar) = down else { return Ok(()) };
        t.relate(me, At, cellar)?;
        describe(t, cellar); // "up: Hall", "tunnel: Garden", the lamp and the rug

        // "take lamp"
        assert!(take(t, me, "lamp")?);
        let carried: Vec<_> = t.sources::<In>(me).map(|(item, _)| t[item].name).collect();
        let lying: Vec<_> = t.sources::<In>(cellar).map(|(item, _)| t[item].name).collect();
        assert_eq!(carried, ["lamp"]);
        assert_eq!(lying, ["rug"]);
        println!("You carry: {}", carried.join(", "));
        Ok(())
    })
}
```

### P2: Who the blacksmith likes

```rust
#![feature(decl_macro)]
use weft::*;

#[derive(Debug)]
pub struct Settings;
kind!(root Settings);

#[derive(Debug)]
pub struct Npc {
    pub name: &'static str,
}
kind!(Npc);

// How well two NPCs know each other, from each side. One fact, two values.
relation!(pub struct Knows(pub u8): Npc <-> Npc, many, cyclic, detach);
// How much the source likes the target. Not mutual.
relation!(pub struct Likes(pub u8): Npc -> Npc, many, cyclic, detach);

module!(pub Village { kinds: [Npc], relations: [Knows, Likes] });
game!(pub Game: Settings [Village]);

/// Everyone `who` likes, most-liked first.
fn liked_by<'t, G: Village>(t: &Turn<'t, G>, who: Id<'t, Npc>) -> Vec<(&'static str, u8)> {
    let mut liked: Vec<_> = t.targets::<Likes>(who).map(|(npc, likes)| (t[npc].name, likes.0)).collect();
    liked.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(b.0)));
    liked
}

fn main() {
    let mut world = World::<Game>::new(|t| {
        let [smith, baker, miller, witch] =
            ["smith", "baker", "miller", "witch"].map(|name| t.spawn(Npc { name }, ()));
        t.relate(smith, (Knows(9), Knows(7)), baker);
        t.relate(smith, (Knows(3), Knows(8)), witch);

use weft::*;

#[derive(Debug)]
pub struct Settings;
kind!(root Settings needs Start, Plays);

#[derive(Debug)]
pub struct Room {

}

kind!(Player needs At);

pub struct Item {
    pub name: &'static str,

kind!(Item rank 0 needs In); // holds nothing

/// A container that can itself be put away. Its rank is in its type:
/// a `Chest<2>` holds `Chest<1>`s and `Item`s, never another `Chest<2>`.
#[derive(Debug)]
pub struct Chest<const R: u8> {
    pub name: &'static str,
}
kind!(Chest<const R: u8> rank R needs In);

set!(pub Thing); // what can be put somewhere
set!(pub Holder); // what things can be put in
is!(Item: Thing);
is!(Chest<const R: u8>: Thing, Holder);
is!(Room, Player: Holder);

// `Chest` is both a `Thing` and a `Holder`, so `In` could loop. `ranked` makes every edge
// go from a lower rank to a higher one, so no loop can be written: `cargo check` refuses it.
// Without `ranked` (or `cyclic`), `game!` below doesn't compile.
relation!(pub struct In: Thing -> Holder, one, ranked, cascade);
relation!(pub struct Exit(pub &'static str): Room <-> Room, many, cyclic, detach);
relation!(pub struct At: Player -> Room, one, refuse);
relation!(pub struct Start: Settings -> Room, one, refuse);
relation!(pub struct Plays: Settings -> Player, one, refuse);

module!(pub Keep {
    kinds: [Room, Player, Item, Chest<1>, Chest<2>],
    relations: [In, Exit, At, Start, Plays],
});
game!(pub Game: Settings [Keep]);

fn room<'t>(t: &Turn<'t, Game>, name: &str) -> Result<Id<'t, Room>, String> {
    t.all::<Room>().find(|&r| t[r].name == name).ok_or(format!("no room {name}"))
}

fn item<'t>(t: &Turn<'t, Game>, name: &str) -> Result<Id<'t, Item>, String> {
    t.all::<Item>().find(|&i| t[i].name == name).ok_or(format!("no item {name}"))
}

fn chest<'t, const R: u8>(t: &Turn<'t, Game>, name: &str) -> Result<Id<'t, Chest<R>>, String>
where
    Game: Has<Chest<R>>,
{
    t.all::<Chest<R>>().find(|&c| t[c].name == name).ok_or(format!("no chest {name}"))
}

fn main() -> Result<(), Box<dyn Error>> {
    let mut world = World::<Game>::new(|t| {
        let hall = t.spawn(Room { name: "hall" }, ());
        let cellar = t.spawn(Room { name: "cellar" }, ());
        t.relate(hall, (Exit("down"), Exit("up")), cellar);
        let big = t.spawn(Chest::<2> { name: "big chest" }, (In, hall));
        let small = t.spawn(Chest::<1> { name: "small chest" }, (In, big));
        t.spawn(Item { name: "coin" }, (In, small));
        t.spawn(Item { name: "key" }, (In, small));
        let me = t.spawn(Player, (At, hall));
        t.spawn(Settings, ((Start, hall), (Plays, me)))
    });
    world.check()?;

    world.turn(|t| -> Result<(), Box<dyn Error>> {
        let (hall, cellar) = (room(t, "hall")?, room(t, "cellar")?);
        let (big, small) = (chest::<2>(t, "big chest")?, chest::<1>(t, "small chest")?);
        let key = item(t, "key")?;

        // 1. Move the outer chest. One edge changes; everything inside comes along.
        t.relate(big, In, cellar)?;
        assert_eq!(t.target::<In>(big), cellar);
        assert_eq!(t.descendants::<In>(cellar).count(), 4);
        assert_eq!(t.ancestors::<In>(key).collect::<Vec<_>>(), [small.up::<Holder>(), big.up(), cellar.up()]);
        assert_eq!(t.sources::<In>(hall).count(), 0);

        // 2. Forbidden states don't compile, so there is nothing to refuse at runtime:
        // t.relate(big, In, big);          // E0277: `Chest<2>` doesn't fit in `Chest<2>`: `In` is ranked
        // t.relate(big, In, small);        // E0277: `Chest<2>` doesn't fit in `Chest<1>`: `In` is ranked
        // t.relate(cellar, In, big);       // E0277: `Room` is not a `Thing`
        // t.unrelate::<In>(big, cellar);   // E0277: `In` is `one`; move it, don't drop it

        // 3. The door is one fact, readable from both sides with its own label.
        let from_hall: Vec<_> = t.targets::<Exit>(hall).map(|(r, e)| (r, e.0)).collect();
        let from_cellar: Vec<_> = t.targets::<Exit>(cellar).map(|(r, e)| (r, e.0)).collect();
        assert_eq!(from_hall, [(cellar, "down")]);
        assert_eq!(from_cellar, [(hall, "up")]);

        // 4. Collapse the cellar. It's doomed now and goes at the end of this turn:
        //    `In` cascades (both chests and their contents), `Exit` detaches.
        t.despawn(cellar)?;
        assert!(t.is_doomed(key));
        t.relate(key, In, hall)?; // grab the key out of the rubble first
        assert!(!t.is_doomed(key));
        // The hall is the start room and the player stands in it: `Start`/`At` refuse.
        assert_eq!(t.despawn(hall), Err(Refused::Held));
        Ok(())
    })?;
    world.check()?;

    world.turn(|t| -> Result<(), Box<dyn Error>> {
        let hall = room(t, "hall")?;
        assert!(room(t, "cellar").is_err());
        assert_eq!(t.all::<Chest<2>>().count() + t.all::<Chest<1>>().count(), 0);
        let left: Vec<_> = t.all::<Item>().map(|i| t[i].name).collect();
        assert_eq!(left, ["key"]);
        assert_eq!(t.target::<In>(t.all::<Item>().next().ok_or("no key")?), hall);
        assert_eq!(t.targets::<Exit>(hall).count(), 0); // no exit leads into the rubble
        Ok(())
    })?;
    world.check()?;

    print!("{world}");
    Ok(())
}

/// A reusable module. A game drops it in with one path in `game!` and one
/// `is!` line naming which of its own kinds can hold items.
pub mod containers {
    use weft::*;

    #[derive(Debug)]
    pub struct Item {
        pub name: &'static str,
    }
    kind!(Item needs In);

    set!(pub Holder);

    relation!(pub struct In: Item -> Holder, one, cascade);
    component!(pub struct Weight(pub u32): Item);

    module!(pub Containers { kinds: [Item], relations: [In], components: [Weight] });

    /// Total weight of everything inside `holder`, at any depth.
    pub fn load<'t, G: Containers>(t: &Turn<'t, G>, holder: Id<'t, Holder>) -> u32 {
        t.descendants::<In>(holder)
            .filter_map(|item| t.get::<Weight>(item))
            .fold(0, |sum, w| sum.saturating_add(w.0))
    }
}

/// `give <noun> to <npc>`. The bounds are the whole story: it touches `In` and `At`
/// and the kinds they connect. `Guards` and `Lit` are unreachable from here.
pub fn give<'t, G>(t: &mut Turn<'t, G>, me: Id<'t, Player>, noun: &str, to: &str) -> Result<String, Refused>
where
    G: Has<In> + Has<At> + Has<Item> + Has<Player> + Has<Npc> + Has<Room>,
{
    let here = t.target::<At>(me);
    let item = t.sources::<In>(me).map(|(item, _)| item).find(|&item| t[item].name == noun);
    let npc = t
        .sources::<At>(here)
        .filter_map(|(walker, _)| t.cast::<Npc>(walker))
        .find(|&npc| t[npc].name == to);
    match (item, npc) {
        (None, _) => Ok(format!("You have no {noun}.")),
        (_, None) => Ok(format!("There is no {to} here.")),
        (Some(item), Some(npc)) => {
            t.relate(item, In, npc)?;
            Ok(format!("You give the {noun} to the {to}."))
        }
    }
}

fn main() -> Result<(), Box<dyn Error>> {
    let mut world = World::<Game>::new(|t| {
        let square = t.spawn(Room { name: "square" }, ());
        let vault = t.spawn(Room { name: "vault" }, ());
        let door = t.spawn(Door { name: "vault door" }, (Opens, vault));
        let gate = t.spawn(Door { name: "gate" }, (Opens, square));
        let me = t.spawn(Player, (At, square));
        let smith = t.spawn(Npc { name: "smith" }, (At, square));
        let lamp = t.spawn(Item { name: "lamp" }, (In, me));
        t.insert(lamp, Lit(true));
        t.insert(lamp, Weight(2));
        t.relate(smith, Guards, door);
        t.relate(smith, Guards, gate); // `opt`: replaces, so the smith guards only the gate
        t.spawn(Settings, (Plays, me))
    });

    world.turn(|t| -> Result<(), Box<dyn Error>> {
        let me = t.target::<Plays>(t.root());
        println!("{}", give(t, me, "lamp", "smith")?); // "You give the lamp to the smith."

        let smith = t.all::<Npc>().find(|&n| t[n].name == "smith").ok_or("no smith")?;
        let lamp = t.all::<Item>().find(|&i| t[i].name == "lamp").ok_or("no lamp")?;
        assert_eq!(t.target::<In>(lamp), smith);
        assert_eq!(t.get::<Lit>(lamp).map(|l| l.0), Some(true));
        assert_eq!(containers::load(t, smith.up()), 2);
        assert_eq!(t.target::<Guards>(smith).map(|d| t[d].name), Some("gate"));
        Ok(())
    })?;
    world.check()?;
    Ok(())
}

// setting can never name a room that's gone.

// Each relation's rules are chosen where it's declared.
// Two-way (`<->`): relate takes both labels, unrelate removes both.
relation!(pub struct Exit(pub &'static str): Room <-> Room, many, cyclic, detach);
// One-way (`->`): a chute you can't climb back up.
relation!(pub struct Chute: Room -> Room, many, cyclic, detach);
// Destroying a chest spills its contents into whatever held it.
relation!(pub struct In: Thing -> Holder, one, ranked, spill);
// A room with someone standing in it can't be destroyed. Arriving runs `arrive`.
relation!(pub struct At: Walker -> Room, one, refuse, on_relate = arrive: Map);
relation!(pub struct Start: Settings -> Room, one, refuse);
relation!(pub struct Plays: Settings -> Player, one, refuse);
relation!(pub struct Likes(pub u8): Npc -> Npc, many, cyclic, detach);

module!(pub Map { kinds: [Room, Player], relations: [Exit, Chute, At, Start, Plays] });
module!(pub Containers { kinds: [Item, Chest<1>], relations: [In] });
module!(pub Folk { kinds: [Npc], relations: [Likes] });

// Parts on or off: two games from the same modules.
game!(pub Full: Settings [Map, Containers, Folk]);
game!(pub Quiet: Settings [Map, Containers]); // no NPCs, e.g. for tests

fn arrive<'t, G: Map>(t: &mut Turn<'t, G>, who: Id<'t, Walker>, room: Id<'t, Room>) -> Result<(), Refused> {
    if t.cast::<Player>(who).is_some() {
        println!("You arrive in the {}.", t[room].name);
    }
    Ok(())
}

fn build<G>(settings: Settings) -> World<G>
where
    G: Map + Containers + Schema<Root = Settings>,
{
    World::new(|t| {
        let hall = t.spawn(Room { name: "hall" }, ());
        let pit = t.spawn(Room { name: "pit" }, ());
        t.relate(hall, Chute, pit);
        t.spawn(Item { name: "lamp" }, (In, hall));
        let box_ = t.spawn(Chest::<1> { name: "box" }, (In, hall));
        t.spawn(Item { name: "coin" }, (In, box_));
        let me = t.spawn(Player, (At, hall));
        t.spawn(settings, ((Start, hall), (Plays, me)))
    })
}

/// NPC behaviour. Only compiles for games that include `Folk`.
fn haunt<'t, G>(t: &mut Turn<'t, G>) -> Result<(), Refused>
where
    G: Map + Folk + Schema<Root = Settings>,
{
    if t.settings().difficulty != Difficulty::Hard {
        return Ok(());
    }
    let me = t.target::<Plays>(t.root());
    let here = t.target::<At>(me);
    let npcs: Vec<_> = t.all::<Npc>().collect();
    for npc in npcs {
        t.relate(npc, At, here)?;
    }
    Ok(())
}

fn play<G>(
    world: &mut World<G>,
    commands: &[&str],
    mut npcs: impl for<'t> FnMut(&mut Turn<'t, G>) -> Result<(), Refused>,
) -> Result<u32, Refused>
where
    G: Map + Containers + Schema<Root = Settings>,
{
    let mut turns = 0;
    for &command in commands {
        let over = world.turn(|t| -> Result<bool, Refused> {
            if turns >= t.settings().turn_limit {
                return Ok(true);
            }
            let me = t.target::<Plays>(t.root());
            let here = t.target::<At>(me);
            match command {
                "jump" => {
                    let below = t.targets::<Chute>(here).map(|(room, _)| room).next();
                    if let Some(below) = below {
                        t.relate(me, At, below)?;
                    }
                }
                "take lamp" => {
                    let lamp = t
                        .sources::<In>(here)
                        .filter_map(|(thing, _)| t.cast::<Item>(thing))
                        .find(|&i| t[i].name == "lamp");
                    if let Some(lamp) = lamp {
                        t.relate(lamp, In, me)?;
                    }
                }
                _ => println!("Nothing happens."),
            }
            npcs(t)?;
            Ok(false)
        })?;
        if over {
            break;
        }
        turns += 1;
    }
    Ok(turns)
}

fn main() -> Result<(), Refused> {
    let mut full: World<Full> = build(Settings { turn_limit: 20, difficulty: Difficulty::Hard });
    full.turn(|t| {
        let start = t.target::<Start>(t.root());
        t.spawn(Npc { name: "ghost" }, (At, start)).map(drop)
    })?;
    play(&mut full, &["take lamp", "jump"], haunt::<Full>)?;

    let mut quiet: World<Quiet> = build(Settings { turn_limit: 5, ..Settings::default() });
    play(&mut quiet, &["take lamp", "jump"], |_| Ok(()))?;
    // play(&mut quiet, &[], haunt::<Quiet>); // doesn't compile: `Quiet` has no `Npc`, no `Likes`

    // Retune mid-game: settings are ordinary data on the root.
    full.turn(|t| t.settings_mut().difficulty = Difficulty::Easy);
    print!("{full}");
    Ok(())
}

relation!(pub struct Start: Settings -> Room, one, refuse);

/// When the player enters a room, they pick up every loose item in it.
fn pick_up<'t, G: Map>(t: &mut Turn<'t, G>, who: Id<'t, Walker>, room: Id<'t, Room>) -> Result<(), Refused> {
    let Some(me) = t.cast::<Player>(who) else { return Ok(()) };
    let loose: Vec<_> = t.sources::<In>(room).filter_map(|(thing, _)| t.cast::<Item>(thing)).collect();
    for item in loose {
        t.relate(item, In, me)?;
        println!("You pick up the {}.", t[item].name);
    }
    Ok(())
}

fn attic<'t>(t: &Turn<'t, Game>) -> Result<Id<'t, Room>, &'static str> {
    t.all::<Room>().find(|&r| t[r].name == "attic").ok_or("no attic")
}

fn main() -> Result<(), Box<dyn Error>> {
    let mut world = World::<Game>::new(|t| {
        let hall = t.spawn(Room { name: "hall" }, ());
        let attic = t.spawn(Room { name: "attic" }, ());
        let crate_ = t.spawn(Chest::<1> { name: "crate" }, (In, attic));
        t.spawn(Item { name: "lamp" }, (In, attic));
        t.spawn(Item { name: "coin" }, (In, crate_));
        t.spawn(Npc { name: "ghost" }, (At, attic));
        let me = t.spawn(Player, (At, hall)); // genesis runs no hooks
        t.spawn(Settings, ((Start, hall), (Plays, me)))
    });

    world.turn(|t| -> Result<(), Box<dyn Error>> {
        let me = t.target::<Plays>(t.root());
        let attic = attic(t)?;

        // A hook that touches another relation: entering runs `pick_up`, which relates `In`.
        t.relate(me, At, attic)?; // prints "You pick up the lamp."
        let carried: Vec<_> = t.sources::<In>(me).filter_map(|(x, _)| t.cast::<Item>(x)).map(|i| t[i].name).collect();
        assert_eq!(carried, ["lamp"]); // the crate stays: `pick_up` only takes `Item`s

        // A chest inside itself doesn't compile; a legal nesting does.
        let crate_ = t.all::<Chest<1>>().next().ok_or("no crate")?;
        // t.relate(crate_, In, crate_);  // E0277: `Chest<1>` doesn't fit in `Chest<1>`: `In` is ranked

        // Reads are total. The `one` edge is stored with the crate, so `target` is an `Id`,
        // not an `Option`, and there is no fallback row behind `t[..]`.
        let holder = t.target::<In>(crate_);
        assert_eq!(holder, attic);
        // let _ = t[holder];             // E0277: `Holder` is a set; it has no data to read

        // Narrowing is identity: `cast` finds this very node among the game's `Npc`s.
        let walkers: Vec<_> = t.sources::<At>(attic).map(|(w, _)| w).collect();
        let npcs: Vec<_> = walkers.iter().filter_map(|&w| t.cast::<Npc>(w)).map(|n| t[n].name).collect();
        assert_eq!(npcs, ["ghost"]);
        assert_eq!(walkers.iter().filter(|&&w| t.cast::<Player>(w).is_some()).count(), 1);
        // let _ = t.cast::<Room>(walkers[0]);   // E0277: `Room` is not a `Walker`
        // let _ = t.target::<At>(walkers[0]);   // E0277: `target` needs a kind; `cast` the walker first

        t.despawn(crate_)?; // `In` spills: the coin moves to the attic at the end of the turn
        Ok(())
    })?;
    world.check()?;

    world.turn(|t| -> Result<(), Box<dyn Error>> {
        let attic = attic(t)?;
        let coin = t.all::<Item>().find(|&i| t[i].name == "coin").ok_or("no coin")?;
        assert_eq!(t.target::<In>(coin), attic);
        assert_eq!(t.all::<Chest<1>>().count(), 0);
        Ok(())
    })?;
    world.check()?;

    print!("{world}");
    Ok(())
}

### P8: The executor hits a snag

````rust
//! `tests/deviations.rs`: after M0, nothing changes without a deviation that pins it.
//!
//! M0 copies P1–P8 out of the decision record, copies its claims table into
//! `docs/design/0001-ecs/claims.md`, writes every gate the table names, records the
//! fingerprint of each of those files in `docs/design/0001-ecs/baseline.txt` (one
//! `<path> <fnv64>` per line), and tags `gates-m0`. From then on the executor never stops.
//! When a program won't compile, a gate fails, or it wants to depart from the design, it makes
//! the smallest change that keeps every claim and appends an entry to
//! `docs/design/0001-ecs-deviations.md` that pins the fingerprint each changed file has
//! *after* the change. For example:
//!
//!     ## D3: P6's `play` spells out a rank bound
//!     - Kind: deviation
//!     - Files: examples/p6.rs
//!     - Pins: examples/p6.rs 9f2c41d07a1be3e8
//!     - Claims: C14
//!     - Why: one line on what forced it
//!     - Evidence: the compiler output, pasted in a fence under the entry
//!
//! A later, unlogged edit to the same file moves its fingerprint off the last pin, and this
//! test fails. A deleted gate fails too. `Kind: shortfall` marks a claim whose gate still
//! fails at the end; the final report lists every shortfall.

use std::fs;
use std::path::Path;

const RECORD: &str = "docs/design/0001-ecs.md";
const LOG: &str = "docs/design/0001-ecs-deviations.md";
const BASELINE: &str = "docs/design/0001-ecs/baseline.txt";
const CLAIMS: &str = "docs/design/0001-ecs/claims.md";
const REPORT: &str = "docs/design/0001-ecs-report.md";

/// Where each frozen program lives in the tree.
const PROGRAMS: [(&str, &str); 8] = [
    ("P1", "examples/p1.rs"),
    ("P2", "examples/p2.rs"),
    ("P3", "examples/p3.rs"),
    ("P4", "examples/p4.rs"),
    ("P5", "game/src/lib.rs"),
    ("P6", "examples/p6.rs"),
    ("P7", "examples/p7.rs"),
    ("P8", "tests/deviations.rs"),
];

/// Every entry fills in each of these. `-` stands for none.
const FIELDS: [&str; 6] = ["Kind", "Files", "Pins", "Claims", "Why", "Evidence"];

fn read(path: &str) -> String {
    let full = Path::new(env!("CARGO_MANIFEST_DIR")).join(path);
    fs::read_to_string(&full).unwrap_or_else(|e| panic!("{}: {e}", full.display()))
}

fn normalize(text: &str) -> String {
    text.lines().map(str::trim_end).collect::<Vec<_>>().join("\n").trim().to_owned()
}

/// FNV-1a, 64 bits, over the normalized text.
fn fingerprint(text: &str) -> String {
    let hash = normalize(text)
        .bytes()
        .fold(0xcbf2_9ce4_8422_2325_u64, |h, b| (h ^ u64::from(b)).wrapping_mul(0x0000_0100_0000_01b3));
    format!("{hash:016x}")
}

/// The fenced block under each `### P<n>: …` heading of the record's `## Frozen API`.
fn frozen(record: &str) -> Vec<(String, String)> {
    let mut out = Vec::new();
    let (mut in_api, mut program, mut fence) = (false, None::<String>, None::<String>);
    let mut body = String::new();
    for line in record.lines() {
        if let Some(close) = &fence {
            if line.trim_end() == close {
                if let Some(p) = program.take() {
                    out.push((p, std::mem::take(&mut body)));
                }
                fence = None;
            } else {
                body.push_str(line);
                body.push('\n');
            }
        } else if line.starts_with("## ") {
            in_api = line.trim_end() == "## Frozen API";
        } else if let Some(heading) = line.strip_prefix("### ").filter(|_| in_api) {
            program = heading.split(':').next().map(str::to_owned);
        } else if in_api && program.is_some() && line.starts_with("```") {
            fence = Some(line.chars().take_while(|&c| c == '`').collect());
        }
    }
    out
}

/// `(path, fingerprint)` for every file M0 froze.
fn baseline() -> Vec<(String, String)> {
    read(BASELINE)
        .lines()
        .filter_map(|line| line.split_once(' '))
        .map(|(path, hash)| (path.to_owned(), hash.trim().to_owned()))
        .collect()
}

/// `(id, fields)` for every `## D<n>: <title>` entry of the log.
fn entries(log: &str) -> Vec<(String, Vec<(String, String)>)> {
    let mut out: Vec<(String, Vec<(String, String)>)> = Vec::new();
    for line in log.lines() {
        if let Some(rest) = line.strip_prefix("## D") {
            out.push((format!("D{}", rest.split(':').next().unwrap_or_default()), Vec::new()));
        } else if let Some((_, fields)) = out.last_mut() {
            if let Some((key, value)) = line.strip_prefix("- ").and_then(|l| l.split_once(": ")) {
                fields.push((key.to_owned(), value.trim().to_owned()));
            }
        }
    }
    out
}

fn field<'a>(fields: &'a [(String, String)], name: &str) -> &'a str {
    fields.iter().find(|(k, _)| k == name).map_or("", |(_, v)| v.as_str())
}

/// `(path, fingerprint)` for every pin in an entry.
fn pins(fields: &[(String, String)]) -> Vec<(&str, &str)> {
    field(fields, "Pins").split(", ").filter_map(|pin| pin.split_once(' ')).collect()
}

#[test]
fn the_baseline_is_the_record() {
    let frozen = frozen(&read(RECORD));
    let baseline = baseline();
    assert_eq!(frozen.len(), PROGRAMS.len(), "the record must freeze P1–P8");
    for ((name, text), (program, path)) in frozen.iter().zip(PROGRAMS) {
        assert_eq!(name, program, "the record's programs are out of order");
        let pinned = baseline.iter().find(|(p, _)| p == path).map(|(_, h)| h.as_str());
        assert_eq!(pinned, Some(fingerprint(text).as_str()), "{path}: the M0 baseline isn't the record's {program}");
    }
}

#[test]
fn nothing_changed_without_a_pin() {
    let log = entries(&read(LOG));
    for (path, then) in baseline() {
        let now = fingerprint(&read(&path));
        if now == then {
            continue;
        }
        let pinned = log
            .iter()
            .rev()
            .flat_map(|(_, fields)| pins(fields))
            .find(|(p, _)| *p == path)
            .map(|(_, hash)| hash);
        assert_eq!(
            pinned,
            Some(now.as_str()),
            "{path} changed since M0, and the last deviation naming it doesn't pin its current fingerprint {now}"
        );
    }
}

#[test]
fn every_entry_is_complete() {
    for (n, (id, fields)) in entries(&read(LOG)).iter().enumerate() {
        assert_eq!(*id, format!("D{}", n + 1), "entries run D1, D2, … with no gaps");
        for name in FIELDS {
            assert!(!field(fields, name).is_empty(), "{id}: no `- {name}:`");
        }
        let kind = field(fields, "Kind");
        assert!(matches!(kind, "deviation" | "shortfall"), "{id}: `Kind` is {kind:?}");
        let pinned = pins(fields);
        for file in field(fields, "Files").split(", ").filter(|f| *f != "-") {
            assert!(pinned.iter().any(|(p, _)| *p == file), "{id}: {file} is listed but not pinned");
        }
    }
}

#[test]
fn every_record_claim_is_kept_or_logged() {
    let (record, claims) = (read(RECORD), read(CLAIMS));
    let log = entries(&read(LOG));
    for row in record.lines().filter(|l| l.starts_with("| C")) {

#[test]
fn every_claim_names_gates_that_exist() {
    let root = Path::new(env!("CARGO_MANIFEST_DIR"));
    let claims = read(CLAIMS);

            } else if let Some((file, name)) = gate.split_once("::") {

}

## What would reopen this

Only this new evidence justifies revisiting the decision:

- **Inference breaks in real code.** Reflexive-`Member` endpoint conversion or value-driven `relate` produces E0283 ambiguity, E0282 "type annotations needed", or rust-analyzer `{unknown}` types in real generic game code beyond P1–P7. The spike's `??ty: 0` result would then not hold.
- **The deletion plan fails.** A fuzzer run, or any program, finds an end-of-turn despawn plan that fails after passing the relate-time and despawn-time checks. That would mean deferred despawn does not keep the graph correct.
- **Cross-crate composition fails.** A `containers`-style module defined in another crate can't be dropped into a `game!` through the `#[macro_export]` callback and an `is!` line. That would break P5's drop-in requirement.
- **Hooks need more than their relation.** A reaction that must touch relations other than its own turns out to be needed, and the `OnRelate<G>` impl with a module bound can't be made to type-check in generic `relate`.
- **Type-level instance acyclicity becomes cheap.** Someone shows it can be done in safe, dependency-free Rust without typestate noise, so that `t.relate(big, In, big)` fails under `cargo check` while ordinary moves compile unchanged. Today no option achieves this.
- **Total lookups become cheap.** Someone shows a safe std representation that makes `t[id]` and `target` on `one` relations total with no fallback, no leak and no central list of kinds. That would remove the unreachable fallback arm and the `Default` requirement, and could change the handle design.
